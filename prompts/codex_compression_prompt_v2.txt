6. COMPUTE THE INTERACTION AND A RELIABLE METRIC

At a common checkpoint after FP warmup and quantizer calibration, for identical calibration inputs obtain:
  t = fixed teacher feature transform
  s_f = frozen-adapter feature with fake quantization bypassed
  s_q = SAME frozen-adapter feature with the target quantization enabled
  f = t - s_f
  q = s_f - s_q
  e = t - s_q = f + q

FP and quantized branches share master weights, adapter, input, fusion and frozen BN state. Disable dropout and observer/state updates for measurement. Save/restore module flags explicitly. Frozen teacher is eval/no_grad. Compute statistics in stable precision; do not retain a teacher graph. The FP residual includes optimization/adapter mismatch and is not a pure causal measure of architecture loss.

Using the identical image/class-balanced expectation throughout, estimate:
  R = E[(f q^T + q f^T)/2]
  Cf = E[f f^T]
  Cq = E[q q^T]
  C = Cf + Cq
  Ce = E[e e^T] = C + 2R

These are UNCENTERED second moments. Centering would remove systematic bias terms and no longer represent the raw-MSE second moments used here; fully centered covariances do satisfy an analogous covariance identity. Ordinary MSE already includes 2*trace(R). The new intervention is the metric constructed below, not the identity itself.

Retain per-image moment contributions and group IDs. Estimate an approximate spectral noise radius with a fixed-seed,200-resample cluster bootstrap over independent source event/site groups:
  delta = empirical95th percentile of ||R_boot - R||_operator.
Resample whole groups, retaining the intended equal-image expectation using group totals/counts. Never bootstrap pixels independently. Use at least max(32,2r) independent groups as a provisional feasibility floor, not as a theorem of sufficient sample size. If less support exists, do not manufacture more observations; record insufficient support and use M=I for the main reliable variant. A raw unshrunk metric may remain a named exploratory ablation.

For symmetric R=V diag(lambda_j) V^T, define:
  p_j = max(lambda_j - delta, 0)
  nu = trace(C)/r
  h_j = min(3, 2*gamma*p_j/(nu+epsilon))
  d_j = (1+h_j) / mean_k(1+h_k)
  M = V diag(d_j) V^T
Fix gamma=1 for the pilot. Use a documented tiny numerical floor in the standardized feature units. When total residual energy is negligible or no positive component survives, set M=I exactly.

Properties to verify: M is symmetric positive definite, trace(M)=r, condition_number(M)<=4. If quantization displacement vanishes while FP transfer error remains nonzero, M approaches I. This replaces v1's normalization by the sum of positive eigenvalues, which could amplify arbitrarily small noise.

Interpret statistical reliability carefully. CONDITIONAL on ||R_est-R_population||op<=delta, each retained empirical direction v satisfies v^T R_population v >= lambda_est-delta>0. The bootstrap only approximates this noise radius; it is not an unconditional95% guarantee, causal identification, or an OOD confidence bound. Log split-group stability as a diagnostic, without tuning against external benchmarks.

Equal trace does not ensure equal feature-loss strength. For EVERY proposed/control metric K, compute and freeze:
  c_K = trace(Ce) / trace(K Ce)
when residual energy/denominator are numerically meaningful. Identity has c_I=1. With negligible error, use identity and c=1. Do not introduce an epsilon that materially changes the matching; handle near-zero cases explicitly.

The feature objective is:
  L_feature(K) = c_K * E_train[(t-s_q)^T K (t-s_q)] / r
This exactly matches initial calibration feature-loss magnitude to MSE. It does not match every training-time gradient. The effective metric c_K*K keeps K's condition number but generally no longer has trace r. Log feature/task loss and gradient norms; do not claim trace normalization alone controls all optimization confounds.

Freeze teacher transform, student adapter, R, delta, M, c_K and beta throughout the primary QAT continuation. No additional FP student forward is required on each training step. Measure final R again for diagnostics but do not silently refresh training weights. A periodically refreshed variant is a later separately specified experiment if the static method first earns further work.

8. DIAGNOSTICS WITH EXACT INTERPRETATIONS

At the common checkpoint and after QAT, compute A=trace(Cf), Q=trace(Cq), X=trace(R). When A+Q is meaningful:
  eta = 2X/(A+Q), in [-1,1]
  total_error_amplification = trace(Ce)/(A+Q) = 1+eta, in [0,2]
  rho = Q/(A+Q)
  |eta| <= 2*sqrt(rho*(1-rho))
  chi_plus = 2*trace(positive_part(R))/(A+Q)
  chi_minus = 2*trace(positive_part(-R))/(A+Q)
  eta = chi_plus-chi_minus; chi_plus+chi_minus<=1.

Report raw diagnostic moments separately from the noise-shrunk training spectrum. Opposing directions can cancel in eta; chi_plus/chi_minus reveal that. These are derived diagnostics, not proven new OOD predictors. Fixed teacher standardization matters; arbitrary feature rescaling changes them. Also report ||M-I||, retained directions, delta and eigenvalues. Large isotropic positive R can still yield M=I after normalization.

On S11 validation ground truth, calculate harmful quantization flips H=P(FP correct,Q wrong) and repaired flips B=P(FP wrong,Q correct), on identical valid support and frozen decision rule. Accuracy_Q-Accuracy_FP = B-H exactly; IoU differences do NOT obey that identity. Report water IoU, pooled two-class mIoU, water precision/recall and image/event aggregation. Use existing boundary diagnostics only if implemented; do not invent a new benchmark. Retain teacher-disagreement diagnostics separately from GT correctness.

The proposal's predictive hypotheses are: robust anisotropic reinforcing directions exist at some smaller/low-bit settings; B3 reduces harmful quantization effects more than B2; and this translates into a better measured size/accuracy frontier. Each can fail independently. Better teacher feature fit is not evidence of better labels or OOD robustness. Teacher-empty or MNDWI-empty images do not establish independently verified dry-scene safety.
