## §A Candidate A — counterfactual normalisation gradient (PARKED)

**Unlock only if,** after task 1.3, either (i) the adopted simulator/floor still leaves median pre-clip norm > 10× FP, or (ii) a measurable accuracy gap persists *and* attribution (task 1.2) shows quantization-induced collapse of healthy denominators that integer-domain arithmetic does not remove. Evidence at the time of writing points the other way: the collapse positions sit at float32 rounding-residue scale (|q| ≈ 5–8e-9; F2) and exact-zero-preserving arithmetic removes the pathology (F3) — consistent with, though not a proof of, residues of mathematically cancelling integer sums — so the premise "collapse harms the *deployed* computation" is unsupported.

Spec (training-time surrogate; the deployed quantized forward is preserved exactly; not the exact gradient of that computation; no convergence guarantee). At every affected head/query: d = D_Q + ε, Y = N_Q/d. D_F comes from a no-grad quantizer-bypass pass of the SAME current weights on the SAME augmented input with identical frozen BN state and aligned positions (restore all QDQ flags; no observer mutation; no accumulated reference gradients). c = 1[D_F > τ_l ∧ D_Q < D_F/16]; d̄ = max(d, D_F/16 + ε) if c else d; all of D_F, c, τ_l, d̄ are stop-gradient. Surrogate VJP for incoming G: grad_N = G/d̄; grad_D = −Σ_value-channels(G·sg(Y))/d̄. Equivalent stop-gradient expression: Y_sur = sg(Y) + ((N_Q − sg(N_Q)) − sg(Y)·(D_Q − sg(D_Q)))/sg(d̄); forward equals Y; both local derivatives are scaled by d/d̄ ∈ (0,1] relative to the ordinary quotient VJP (local bound only). τ_l = first percentile of strictly positive FP D on the TRAIN calibration pool (floor at ε; record "too sparse" instead of inventing a threshold). Ratio 16 is a preregistered default; at most one ratio-4 sensitivity after a source gate.
Controls: original; backward-only denominator floor with exact forward (the conventional rival); this rule; a separately labelled forward floor / higher-precision projection. If the counterfactual rule loses to the simple floor, report it as unnecessary. A lower gradient magnitude alone is not success — require adequate actual updates and improved accuracy or teacher-risk under matched compute.
Tests: forward equality for random, tiny-denominator and zero-numerator inputs; grad_N/grad_D against the specified VJP with stop-gradient values held fixed (do **not** demand finite differences of the unchanged forward to match the deliberately modified backward); inactive when QDQ is off or D_Q = D_F (matches ordinary gradients); head/query alignment, broadcast axes and reduction over value channels; reference pass preserves flags/observers/BN buffers/RNG order; export contains the original quotient only.
Novelty note: Qin et al. (EMNLP 2022) already identify unbounded gradients from attention scaling; Kim et al. (EACL 2023) intervene with intact teacher signals in quantized propagation. A student-counterfactual, inference-preserving *backward* rule would differ — but only a win over the simple floor would make that difference matter.

## §B Candidate B — distill excess task loss (conditional, Stage 5)

Binary logits, margins m = z_water − z_background, temperature T: a = m_F/T, b = m_Q/T, p_F = σ(a), p_T = σ(m_teacher/T), p_Q = σ(b), ℓ(p,u) = softplus(u) − p·u. Exact identity (re-derived): Δ = T²[ℓ(p_T,b) − ℓ(p_T,a)] = T²[(p_F − p_T)(b − a) + KL(Bern(p_F)‖Bern(p_Q))]. The KL term is ≥ 0; the signed first term can offset it; Δ < 0 means quantization improved agreement with the teacher under this loss — not that it improved ground truth. Use stable log-sigmoid/log-softmax arithmetic; do not clamp probabilities and then claim equality. Same CURRENT weights with QDQ off/on for diagnostics; per image and event report H_T = E[max(Δ,0)], B_T = E[max(−Δ,0)], E[Δ] = H_T − B_T, sign proportions, quantiles, the signed and KL terms separately, class and boundary/interior breakdowns from valid training pseudo masks with teacher-confidence strata and support counts; equal image mass with fixed valid-pixel reductions (class-balanced summaries separately).
Auxiliary: S_0 = frozen pre-QAT FP anchor (no-grad, like the teacher). d_i = T²[KL(p_T,i‖p_Q,i) − KL(p_T,i‖p_S0,i)]. ψ_k(d) = 0 (d ≤ 0); d²/(2k) (0 < d < k); d − k/2 (d ≥ k); derivative in [0,1]. k = 75th percentile of positive d on the TRAIN calibration pool, ≥ 1e-6, frozen; no positive d ⇒ record a degenerate auxiliary and skip. L = L_base + λ·E_valid[ψ_k(d)]; λ fitted on ≤ 32 replayable TRAIN minibatches after the chosen backward rule is active to a median auxiliary/task gradient ratio of 0.1 on a fixed common block (disclose whole-model ratios; reject degenerate ratios); freeze. Note the gradient flows only through KL(p_T‖p_Q): the auxiliary re-weights the same term per pixel by (1 + λψ′) — a hard-example weighting anchored on the FP student that does not penalise beating the anchor. Hence the controls in Stage 5 (generic teacher-entropy/KL weighting, rule-disagreement weighting, full-space MSE). If only generic hard-pixel weighting is needed, narrow the claim.
Tests: float64 identity for random and extreme finite margins at T = 1 and 4; H_T − B_T = mean Δ; GT flip identity on controlled cases; zero auxiliary gradient for d ≤ 0; bounded derivative; no gradient into S_0 or the teacher.

## §C Spectral input rotation (PARKED; PTQ-only test allowed)

On the normalised six-channel input z, rotate the (green, SWIR1) pair by a fixed orthogonal 2×2 U (one axis ∝ σ_green·z_green − σ_SWIR1·z_SWIR1, the perpendicular unit axis for the other), four bands unchanged; replace the first conv's input-channel weights W by W′ = W·Uᵀ at each kernel position, so W′(Uz) = Wz exactly (U linear with no offset ⇒ zero padding stays zero; the physical contrast has a nonzero mean offset in normalised coordinates — do not insert a mean shift). Place U before the first activation quantizer, recalibrate with the matched inputs, count its deployment overhead, compare identity / this rotation / seeded random orthogonal / TRAIN-PCA at identical precision. **Why parked:** F5 shows an 8-bit stem alone recovers +7.2 pp, keeping the input stem at 8 bit is standard and nearly free, and quantization-friendly rotations are an established concept; novelty would need task-specific evidence beyond random/PCA rotations, a real export and a focused literature comparison. Test, if at all, at fixed checkpoints (PTQ) against the 8-bit stem; if the quantizer is invariant to the transform, record it as inert.

## §E Integer-domain fake-quant conv — reference sketch (what the supervisor probe used)

```python
def int_domain_forward(self, inp):          # replaces FixedQATConv2d.forward when quantization is enabled
    if not self.fake_quant_enabled:
        return self._conv_forward(inp, self.weight, self.bias)
    sa = float(self._act_scale[0]); amin, amax = _range(self.activation_bits); wmin, wmax = _range(self.weight_bits)
    xs = inp / sa; xr = torch.round(xs.detach())
    x_ste = torch.clamp(xr, amin, amax) + (xs - xs.detach()) * ((xr >= amin) & (xr <= amax)).to(inp.dtype)
    sw = self._w_scale.view(-1, 1, 1, 1); ws = self.weight / sw; wr = torch.round(ws.detach())
    w_ste = torch.clamp(wr, wmin, wmax) + (ws - ws.detach()) * ((wr >= wmin) & (wr <= wmax)).to(self.weight.dtype)
    out = F.conv2d(x_ste, w_ste, None, self.stride, self.padding, self.dilation, self.groups)  # exact on integers
    out = out * (sa * self._w_scale.view(1, -1, 1, 1))                                          # dequantise after accumulation
    return out + self.bias.view(1, -1, 1, 1) if self.bias is not None else out
```
Conditions: the integer accumulation is exact in float32 only while |Σ x_int·w_int| < 2²⁴ (assert it from fan-in and bit-widths; use float64 accumulation otherwise); unsigned grids use amin = 0, amax = 2ᵇ−1 and their own calibrated scale; BN/bias stay float. Supervisor results with exactly this form: gradient norms and parity in F3; the divergence versus the float32 op first appears at the LiteMLA proj output (`receipts/int_domain_divergence.txt`), i.e. in the attention quotient, not in the convs.
